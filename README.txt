HORNETS MATCHDAY - PHONE APP PROTOTYPE

Quick test on your work PC:
1. Open the hornets-matchday folder.
2. Double-click index.html.
3. It will open in Chrome or Edge.
4. Your changes are saved in that browser automatically.

Included:
- Squad imported from U23 Matchday Planner(8).xlsm
- 4-3-3 and 3-5-2 formation switching
- Automatic position conversion between formations
- Availability, starter and substitute selection
- Captain and vice-captain roles
- Live pitch and bench
- Duplicate and unassigned position warnings
- Add new players
- Browser storage

To install it properly on an iPhone Home Screen, the folder needs to be hosted on a normal HTTPS web address. The manifest and service worker are already included for that next step.
